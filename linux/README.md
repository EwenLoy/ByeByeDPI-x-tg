# ByeByeDPI x tg — Linux (Fedora)

Графическое приложение на GTK4 + libadwaita с тем же экраном, что и на Android:
большая кнопка включения ByeDPI по центру, внизу карточки «Редактор»,
«Настройки», «Подбор», «Списки», «TG WS Прокси», «Подключить прокси в Telegram».

## Установка

```bash
sudo dnf install -y git gcc make cargo rust python3 python3-gobject gtk4 libadwaita curl

./linux/build.sh      # собирает ciadpi и libtgwsproxy.so в linux/dist
./linux/install.sh    # ярлык в меню + команда byebyedpi-tg (в ~/.local, без sudo)
```

Запуск без установки: `python3 linux/app.py`. Удаление: `./linux/uninstall.sh`
(`--purge` — вместе с настройками).

## Как это устроено

| Android | Linux |
|---|---|
| ByeDPI внутри приложения | отдельный процесс `ciadpi`, SOCKS5 `127.0.0.1:1080` |
| Режим «VPN» | режим «Системный прокси»: GNOME — через `gsettings`, KDE Plasma — через `kwriteconfig6/5`; прежние значения восстанавливаются при выключении (и после аварийного завершения) |
| Режим «Прокси» | режим «Прокси»: SOCKS5 указывается в нужных приложениях вручную |
| TG WS: `libtgwsproxy.so` через JNA | та же библиотека через `ctypes` в отдельном процессе `tg_proxy_runner.py`, порт `1082` |
| Подбор стратегий | каждая стратегия запускается во временном `ciadpi` на свободном порту, сайты проверяются через `curl`; основное подключение не прерывается |
| Списки, история команд, «Проверить TG WS», логи TG WS | есть |
| Автозапуск при загрузке | автозапуск при входе в систему (`~/.config/autostart`) |
| VPN-специфичное: DNS, IPv6, фильтр приложений | нет — на Linux это не нужно в режиме прокси |

## Telegram

1. Нажмите «TG WS Прокси». Прокси начнёт слушать `127.0.0.1:1082` и **ждать**,
   пока Telegram подключится — статус «ждёт подключения» и подсказка видны под кнопкой.
2. Нажмите «Подключить прокси в Telegram» — откроется Telegram Desktop с
   предложением добавить MTProto-прокси (ссылка заодно копируется в буфер).
   Если Telegram Desktop не зарегистрировал ссылки `tg://`, откроется браузер
   со ссылкой `t.me/proxy`, или её можно вставить в любой чат Telegram.
3. Как только Telegram начнёт ходить через прокси, статус сменится на
   «Telegram подключён» с трафиком.

Ошибки (порт занят, ядро не собрано, процесс упал) остаются на экране до
следующего нажатия кнопки.

## Файлы

- `app.py` — окно и главный экран; `pages.py` — остальные экраны; `ui_common.py`, `style*.css`, `icons/` — оформление
- `process_manager.py` — запуск процессов, логи, сборка командной строки ciadpi
- `tg_proxy.py`, `tg_proxy_runner.py` — Telegram WS-прокси
- `system_proxy.py` — системный прокси GNOME/KDE
- `strategy_tester.py` — подбор стратегий
- `storage.py` — настройки (`~/.config/byebyedpi-tg/settings.json`), списки и история (`~/.local/share/byebyedpi-tg/`)
